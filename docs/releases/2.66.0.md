## NT Helper 2.66.0 — CV routing and Step Sequencer controls

### Routing
- Visualize configured parameter CV modulation in Canvas, Bus Lanes, Signal Flow and Accessible List views. Inspect parameter targets, source snapshots and inferred contributors without changing mappings. Routing shows configured topology, not measured modulation or voltages.
- Distinguish raw-bus signal paths from mapped CV paths, with named inputs and mapping-editor actions. Routing allocation, consolidation and slot-order guards protect configured CV buses and source snapshots.
- Show configured NTX-8CV output taps from the connected NT's observed Module Settings. This supports one NTX on Channel Group 1–8; it does not autodetect an expander or its independent channel-group selection. The second audio bank and locally selected NTX audio enables are outside this feature's scope.
- NTX configuration discovery requires recognized NT firmware 1.20 or newer with settings protocol support. Unsupported or unresolved configurations are not presented as confirmed active routes. Routing does not configure the NTX or write module settings.

### Step Sequencer and layout
- Open the native Step Sequencer editor with the shared Controller toggle. Standard provides the ordinary parameter pages; Spreadsheet remains available. The redundant Parameter Pages dialog has been removed.
- Preserve editor-local lane and quantization state while switching views on the same mounted slot. Pending edits settle before switching; stale edits are cancelled after sequence, algorithm or connection changes. Sequence selection follows the parameter's actual range, including Sequence 32 when supported.
- Improve narrow-window sequencer controls and tighten the algorithm sidebar's right spacing.

### Verification boundaries
Automated regression coverage includes routing safety, accessibility semantics, stable asynchronous layout and sequencer edit lifetimes. This release task does not validate physical audio, CV voltages, expander presence, or hardware write/flash persistence. NT Settings, introduced in 2.65.0, still requires recognized firmware 1.20 or newer and settings protocol support; a version string alone does not establish support.

GitHub downloads, Play internal uploads and TestFlight uploads are distinct from production promotion. Apple review and automatic release after approval remain subject to App Review.
