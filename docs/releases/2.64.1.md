## NT Helper 2.64.1 — Firmware 1.20 mappings and preset-loading reliability

This release completes the partially published 2.64.0 release. Android release builds now use JDK 21 so the upgraded release lint can run without disabling checks. App Java/Kotlin bytecode targets remain 17. The changes below cover the update from 2.63.3.

### Firmware 1.20 mappings
- Added MIDI view-change and MIDI/i2c bypass controls for recognized firmware 1.20 or newer, including beta versions, when mapping format v8 has been observed.
- Preserve bypass flags and reserved mapping bits when editing, saving, sharing templates, or making partial MCP mapping updates. Incompatible mapping writes are blocked instead of silently losing newer settings.
- Existing firmware remains supported without exposing unsupported controls. Firmware 1.20 mapping behavior is covered by automated regression tests; live-hardware validation of these new mapping controls has not been performed.

### Preset loading
- Wait for the NT to finish building a loaded or appended preset before synchronizing its slots, avoiding empty or stale results immediately after choosing a preset in the file browser.
- Show slot-loading progress and stop waiting on cancellation or disconnection, with bounded fallback behavior when a preset's expected slot count is unavailable or cannot be reached.

### Toolchain and platform maintenance
- Updated to Flutter 3.50 and Dart 3.14 with refreshed app and native dependencies, including MIDI, file picking, database, camera, and desktop integration packages.
- Migrated Material and Markdown rendering and adapted file selection/export handling, including cancellation and Android content destinations.
- Updated Android build tooling and pinned the native USB-video library source. Refreshed macOS Swift Package Manager integration.
- macOS App Store submissions now request automatic release after App Review approval. Approval itself remains Apple's decision; publishing this GitHub release does not imply store approval or production promotion.
- Consolidated project guidance and Windows runner documentation.
